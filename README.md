# 每日食记 · Dayly Food

**中国人的饮食记录 App。吃之前拍一张，就知道这顿多少卡。**

不用注册、不用登录、数据只在你手机上。装好就能用，不连网也能记账。

---

## 它能帮你做什么

**拍一张就记一顿**
包装食品拍营养成分表，一秒读出热量和蛋白质脂肪碳水；一盘菜拍一下，自动认出是什么、大概多少克。

**知道今天还能吃多少**
填一次身高体重目标，算出你每天该吃多少。首页一个圈告诉你「今天吃了 1404，还能吃 718」。

**找得到你真正吃的东西**
内置 400+ 中式食物：香干炒肉、冬瓜排骨汤、蜜雪冰城珍珠奶茶……不是只有「米饭」「鸡胸肉」这种。

**自己做的菜也能算**
选几样食材、选烹饪方式（炒/蒸/炸/炖），自动算油、算总热量，存成自己的菜，下次一点就记。

**饮料按毫升算，奶茶分杯型**
可乐一罐 330、一瓶 500、大瓶 1000；奶茶中杯 / 大杯 / 超大杯，点一下就行。

**数据是你的**
一键导出备份文件，换手机能恢复。不上传、不分析、不卖数据。

## 三分钟上手

### 第一步：填一次个人信息

打开 App 只有这一屏要填：

```
性别 · 年龄 · 身高 · 体重  →  活动量（久坐 / 轻度 / 中度 / 高强度 / 极高）
                            →  目标（减脂 / 维持 / 增肌）
```

填完点「保存」，它算出你每天该吃多少热量和三大营养素。以后想改，在「我的 → 个人信息」。

### 第二步：记下你吃的东西

底部三个标签：**记录 · 查找 · 我的**。记东西有两种主路径：

| 你想做的事 | 怎么做 |
|---|---|
| 知道自己吃了什么 | 「查找」搜名字 → 点一条 → 选份量 → 选早/午/晚/加餐 |
| 手边有包装 | 点右下角**相机**拍营养成分表 |
| 桌上有菜 | 点右下角**相机**拍菜（需要先开 AI，见下） |
| 自己做的 | 「查找 → + 组合菜品」，选食材和做法 |

记完之后首页会自动算：「最近吃过」里会出现你刚记的食物，下次一点就按上次的份量重记。

### 第三步：看今天吃得怎么样

首页那个圈就是进度。下面三条看蛋白质 / 脂肪 / 碳水吃够没有：

```
蛋白质  51 / 150 g     ← 紫色到顶说明吃超了
脂肪    53 / 58 g
碳水   168 / 247 g
```

想改某一条的份量：点那一行就能改克数；想删，长按或点进去删除。

## 拍照怎么用

右下角有**两个按钮**：上面是相册，下面是相机。

### 拍到营养成分表 → 完全离线，不要钱

```
点相机 → 拍标签 → 等 1-2 秒
  ↓
显示：每 100 克 436 kcal（标签原文 1823 kJ ÷ 4.184）
     蛋白 9g · 脂肪 12g · 碳水 63g
  ↓
填个名字、写吃了多少克、选哪一餐
  ↓
保存 → 这个食品进你的库，下次直接搜得到，不用再拍
```

这一步**不需要联网、不需要 AI Key、不花钱**。识别都在手机里做。

### 拍到一盘菜 → 需要开 AI

拍完弹窗里会列出「香干炒肉 200g」「米饭 150g」，每一样可以勾选、可以改克数，库里有的会标「库里已有」，没有的标「AI 估算」并自动存进你的库。

> 菜品识别要靠大模型，得你自己填一个接口（见下一节）。不填也能用 App，只是拍菜不会认。

### 拍失败了怎么办

弹窗会直接告诉你原因，并且显示**它到底读到了什么文字**。常见情况：

| 提示 | 怎么办 |
|---|---|
| 没读出营养成分表 | 让表格占满画面、对正、避开反光；或者直接「手动添加」 |
| 这张里没有营养成分表 | 如果确实是菜，改用拍菜（要开 AI） |
| 想拍照认菜，需要打开「识图记餐」 | 去「我的 → AI 设置」打开开关 |
| 识别超时 | 检查网络，或重拍 |

## 要不要开 AI？（可选）

**不开也一样能用**：搜食物、记三餐、算热量、拍营养成分表，全都正常。

| | 不开 AI | 开了 AI |
|---|---|---|
| 搜食物、记餐、算热量 | ✅ | ✅ |
| 拍营养成分表 | ✅ 离线免费 | ✅ |
| 拍一盘菜认菜 | ❌ | ✅ |
| 花费 | 0 元 | 按你用的服务商计费，App 不代收 |

### 怎么填

「我的 → AI 设置」，三项（没有一堆平台让你挑，按你用哪家填哪家）：

```
接口地址   https://api.deepseek.com     ← 只填域名也行，会自动补全
模型名     deepseek-flash               ← 识图也是这个模型
API Key    sk-...
```

填完点「测试连接」，它会真发一次请求告诉你通不通。不通用会显示 HTTP 码、实际地址、模型名和服务端原话，照着改就行。

**省钱相关的设计**：识图、每日总结、每周报告三个开关，后两个默认是关的；每天的调用次数有上限（默认 20 次），到了就当天停用，记账不受影响；设置里能看到累计用了多少 token、大概花了多少钱。

## 安装

1. 打开 [最新版本](https://github.com/dyhdream/dayly-food/releases/latest)，下载 `.apk`
2. 手机上点开安装，允许「安装未知来源应用」
3. 需要 **Android 8.0 以上**，APK 约 21 MB

装过旧版可以直接覆盖升级，记录不会丢。装好后 App 会自己检查更新。

## 常见问题

**数据存在哪里？卸载会丢吗？**
只存在你手机里，卸载就没了。建议偶尔「我的 → 数据备份 → 导出备份」，把 JSON 文件存到网盘。

**换手机怎么办？**
新机装好 → 填个人信息 → 「恢复备份」选那个 JSON 文件。API Key 不在备份里，需要重新填一次。

**没有网络能用吗？**
能。除了拍菜识别和检查更新，其他功能都不需要网络。

**用 AI 会很贵吗？**
看服务商。拍一张菜大约几分钱以内，日常记餐一天用不到几次；App 里有每日上限，不会失控。

**为什么有些菜的热量写着「估」？**
市售成品菜没有官方营养数据，只能给典型值。这类条目都标了 `verified=0`，界面写「市售典型值」，**估算值，别当精确数据**。

**装不上 / 打开闪退？**
- 提示「应用未安装」：确认是 Android 8.0 以上，且手机是 arm 架构（近几年的手机都是）
- 打开闪退：请把手机型号和 Android 版本发到 [Issues](https://github.com/dyhdream/dayly-food/issues)

**能同步到微信运动 / 苹果健康吗？**
不能，也没这个计划。数据只在本机。

## 隐私

- 没有账号、没有服务器、没有埋点统计
- 照片只在你**主动拍照并开启识图**时才发给你自己填的服务商；拍营养成分表时**完全不上传**
- API Key 加密存在手机的安全区里，不写日志、不进备份文件
- 卸载即清除全部数据
